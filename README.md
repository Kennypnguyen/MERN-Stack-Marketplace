# MERN Stack Marketplace

A web marketplace that allows users to create an account to either buy or sell products using Stripe to help process payments. Seller accounts are able to create shops and display products for buyers to view and purchase. Sellers are then able to manage and keep track of orders once products are purchased. Website also includes product search and suggestions.

### Languages, technologies, and tools used:

* Languages: Javascript
* Technologies: MongoDB, Express.js, Node.js, and React.js
* Tools: Visual Studio Code, Stripe Account

### What you need to run code:

* Node
* NPM or Yarn
* MongoDB
* Your own Stripe Account 

### How to run the code

1. First make sure MongoDB is running
2. Update config.js file with your own Stripe API keys and Stripe Connect Client ID
3. Using the command line in the folder: 
   - To install dependencies, run ```  npm install  ``` or ``` yarn ```
   - To run application, run ```  npm run development  ``` or ``` yarn development ```
4. Open [localhost:3000](http://localhost:3000/) in the browser
